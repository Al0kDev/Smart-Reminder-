# Smart-Reminder-

![Screenshot 2025-05-02 215936](https://github.com/user-attachments/assets/e7a43ea6-8b49-4dc6-bbaa-4cb9098c000b)

A Laravel-based web application designed to help users create and manage reminders effectively. This project serves as a smart reminder system for scheduling and tracking tasks or events.

#✨ Features

📝 User Authentication – Register and log in to manage your own reminders.

📅 Create Reminders – Add reminders with a title, description, and due date.

🔔 Smart Notifications – Notify users about upcoming reminders.

✅ Manage Tasks – Edit or delete reminders as needed.

📊 Dashboard View – Display a list of all scheduled reminders.

🧩 Session Management – Secure handling of user sessions.

📱 Responsive Design – Optimized UI for desktop and mobile screens.



#🚀 Tech Stack

Framework: Laravel 10

Language: PHP 8.1+

Frontend: Blade (Laravel Templating)

Styling: TailwindCSS (if included) or Bootstrap (if applicable)

Database: SQLite (default), MySQL optional

Tooling: Composer, Artisan, Vite, NPM
